# OneDrive連携の設定手順(初回のみ)

JWWリーダーの「OneDrive」ボタンから、OneDrive(大学・会社のアカウント)のJWWを直接開くための設定です。
必要なのは、Microsoft Entra(旧Azure AD)でアプリを1つ登録して、その「アプリケーション(クライアント)ID」を
JWWリーダーに入力することだけです。クライアントシークレット(パスワード)は使いません。

## 仕組み

- ブラウザ上の認証ライブラリ(MSAL)で、Microsoftにサインインします(PKCE方式)。
- 取得したトークンで、Microsoft Graph API(`graph.microsoft.com`)から、JWWの中身を端末に直接ダウンロードします。
- 図面は、Microsoft以外のサーバー(このアプリの配信元を含む)には送られません。
- 要求する権限(いずれも「委任」=サインインした本人の権限の範囲で動く):
  - `Files.Read.All`: 自分のファイルと、共有ライブラリ(Teams・SharePoint)のファイルを読む。組織によっては**管理者の同意**が必要。
  - `Files.Read`: 自分のOneDriveのファイルだけを読む。通常は管理者の同意なしで使える。
  - 前者が許可されない場合は、自動で後者に切り替えます。どちらも「読み取り専用」で、ファイルの変更・削除はできません。

## 手順

1. ブラウザ(パソコン推奨)で Microsoft Entra 管理センター(https://entra.microsoft.com/)を開き、サインインする。
   - アプリの登録が、大学のアカウントでできるかどうかは、組織の設定によります。できない場合は、個人のMicrosoftアカウントで試します。
2. 「Entra ID」→「アプリの登録」→「新規登録」を選ぶ。
3. 次のように入力して「登録」を押す。
   | 項目 | 入力 |
   |---|---|
   | 名前 | `JWWリーダー`(何でも可) |
   | サポートされているアカウントの種類 | **「任意の組織ディレクトリ内のアカウント(任意の Microsoft Entra ID テナント – マルチテナント)と個人の Microsoft アカウント」** |
   | リダイレクト URI | プラットフォームは**「シングルページ アプリケーション(SPA)」**、値は `https://tomo57810-maker.github.io/JWW-Reading/`(最後の `/` まで、そのまま) |
4. 登録後の「概要」画面にある**「アプリケーション(クライアント)ID」**をコピーする(`xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx` の形)。
5. JWWリーダーの「OneDrive」ボタンを押し、IDを貼り付けて「保存して進む」を押す。
6. 「Microsoftでサインイン」を押し、大学のアカウントでサインインする。権限の許可を求められたら、内容を確認して承認する。

## うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| 「組織の設定により、このアプリの利用が許可されていません」 | 組織が、ユーザー自身による同意を禁止しています。情報システムの管理者に、このアプリ(クライアントID)への同意を依頼してください。 |
| サインインはできるが、共有ライブラリ(「業務用-personal」など)の中身が出ない | `Files.Read.All` が許可されず、`Files.Read` に切り替わっている可能性があります。上と同じく、管理者の同意が必要です。 |
| 「リダイレクトURIが一致しない」(AADSTS50011) | 手順3のリダイレクトURIが、URLと1文字でも違っています(末尾の `/` など)。 |
| 「このアプリは、アカウントの種類に対応していません」 | 手順3の「サポートされているアカウントの種類」を、マルチテナント+個人アカウントにしてください。 |
| サインインの画面が開かない | ポップアップがブロックされています。自動で画面遷移の方式に切り替わるので、サインイン後に、もう一度「OneDrive」を押してください。 |

## 補足

- アプリケーション(クライアント)IDは、秘密情報ではありません(悪用してもパスワードにはなりません)。この端末のブラウザに保存されます。
- 設定を変える・やり直すときは、「OneDrive」画面の「IDを入れ直す」を使います。
- `js/config.js` の `CLIENT_ID` にIDを書いておくと、入力が不要になります(複数の端末で使うとき向け)。
