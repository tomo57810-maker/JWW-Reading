# JWW-Reading

JWW(Jw_cad)図面を、スマホ・タブレットのブラウザで開いて見るためのWebアプリです。
図面はブラウザの中だけで処理され、外部には送信されません。

## 現在できること(段階①)

- JWW/JWCファイルを開く(「開く」ボタン、またはドラッグ&ドロップ)
- 指2本のピンチ・ドラッグ、マウスホイール、ダブルクリックで拡大・移動
- Jw_cadと同じ「レイヤグループ → レイヤ」の2段表示(グループごと・レイヤごとの表示/非表示、番号 0〜F 付き、名前で絞り込み、図形のないレイヤは既定で非表示)
- 背景色の白/黒の切り替え
- ホーム画面にインストールして、通信がなくても起動(PWA)
- 他のアプリの「共有」からJWWを受け取る(Android。下記「共有から開く」)
- 「OneDrive」ボタンから、大学・会社のOneDriveのJWWを直接開く(読み取り専用。初回設定が必要: [docs/ONEDRIVE.md](docs/ONEDRIVE.md))
- 線・円・円弧・文字・塗りつぶし・ブロック(部品)の表示

## 測定・注釈・書き出し

- 画面下のツールバーで、モードを切り替える(指1本=ツール、指2本=拡大・移動)。
  - **寸法**: 2点をタップ。図面の端点・円や円弧の中心に吸着し、実寸の長さを表示。
  - **面積**: 角を順にタップして「完了」。実寸の面積(m²)を表示。
  - **ルート**: 経路を順にタップして「完了」。配管ルート修正案などの総延長を表示。
  - **赤ペン**: 指でなぞって書く。 **コメント**: 文字を置く。 **消す**: 注釈をタップして消す。
- **図形**: 図面の図形そのもの(流し台など)を編集する。
  - 選び方: 範囲をなぞって選ぶ(四角の中に完全に入った図形)/ タップで1つ選ぶ。「追加選択」をオンにすると、選び足し・選び外しができる。
  - 枠をドラッグで移動、角をドラッグで拡大縮小、枠の上の○をドラッグで回転(15度ごとに吸い付く)。ボタンで ↺90° ↻90° ×1.25 ×0.8、複製、削除。「戻す」で1つ前に戻る。
  - 原本のJWWは書き換えない。編集は「操作の記録」として端末に保存し、表示・PDFの出力のたびに、原本へ当てはめる(「書出」の「図形の編集をすべて元に戻す」で、全部取り消せる)。
  - **伸縮(寸法を変える)**: 図形を選び、「伸縮」→ 動かす側を窓で囲む → ドラッグか「数値」(実寸mm)で動かす → 「完了」。窓の中の端点だけが動くので、幅だけ・奥行きだけを変えられる(例: 流しW1200→W900は、右半分を囲んで、横 -300)。円・円弧・文字は、中心が窓に入っていれば、まるごと動く。
  - **吸着**: 移動のとき、動かす側の端点・中点・中心が、他の図形の端点・中点・中心・四半点・基準点に近づくと、ぴったり重なる(印と名前が出る)。
  - **基点移動**: 図形を選び、「基点移動」→ 動かす側の点(端点・中点)をタップ → 移動先の点をタップ(2本指で動かして探せる)。
  - 回転・一様な拡大縮小(↺↻・×1.25・×0.8・角のドラッグ)では、円・円弧・文字も追従する。縦横で別の倍率にする拡大縮小は、円が楕円になるため、伸縮で行う。
- **基準点**: 「基準点」→ 基点(端点・中点などに吸着)をタップ → 横・縦の距離(実寸mm)を入力すると、その位置に「基準点」を打つ(例: 柱面から1000の所)。基準点は、寸法・移動の吸着の対象になる。
- 縮尺は、Jw_cadの書込レイヤグループの縮尺を既定にし、画面で変更できる(寸法・ルートは用紙mm × 分母、面積は × 分母の2乗)。
- 注釈は、原本のJWWを書き換えず、端末内(IndexedDB)に自動保存する。同じ内容の図面を開くと呼び戻す。JSONファイルでの書き出し・読み込みもできる。
- 「書出」で、図面と注釈を、用紙の大きさのPDFにする(画像形式のPDF。標準=長辺4000px、高画質=長辺7000px)。

## できないこと(今後の予定)

| 段階 | 内容 |
|---|---|
| ② | 注釈をJWW/DXFとして書き出す(Jw_cadで開ける形) |
| ③ | レイヤごとの高さ・管径の表にもとづく3D表示 |

既知の制限:

- 線種のうち `SXF_USER_*`(ユーザー定義線種)は、実線で表示します。
- レイヤの状態が「非表示」(状態0)のものは、最初から隠します(Jw_cadの状態の意味は、知識にもとづく解釈です)。
- ezjwwの変換結果にない図形(件数は画面下に表示)は表示しません。
- 画面の色はJWWの色番号(AutoCAD色番号に変換されたもの)にもとづく表示で、Jw_cadの画面と色が違うことがあります。

## 共有から開く(Android)

1. Chromeでこのページを開き、メニュー(︙)の「アプリをインストール」または「ホーム画面に追加」を選ぶ。
2. 共有先の一覧から「JWW」を選ぶ。
   - OneDriveアプリの「共有」は、ファイル本体ではなく**リンク(URL)**を渡すため、図面は開けない(その旨を画面に表示する)。
   - OneDriveで「保存」して端末に置いたファイルを、マイファイルなどから共有すれば、ファイル本体が渡る。
3. 受け取ったファイルは、アプリの中で開いたあと、端末内の一時コピーを自動で消す。

注意: 共有先に出るかどうかは、共有する側のアプリが付けるファイルの種類(MIMEタイプ)によって変わるため、
実機で確認が必要です。共有先に出ない場合は、従来どおり「開く」から選んでください。

## 使い方

静的なファイルだけで動きます(ビルド不要)。

```bash
npm install        # 初回のみ
npm run serve      # http://localhost:8080 で開く
npm test           # 単体テスト
```

`vendor/` の中身は `npm run vendor` で作り直せます(ezjwwのWebAssemblyをブラウザ用に変換したもの)。
アイコンは `python3 scripts/make-icons.py` で作り直せます。画面部品を更新したときは、`sw.js` の `CACHE` の版番号を上げてください。

- 業務の図面ファイル(`.jww` / `.jwc`)はリポジトリに入れないでください(`.gitignore`で除外しています)。
